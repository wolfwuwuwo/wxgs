# 光学仿真实验平台 v4.0 更新说明

在保持原有页面格式（单页 SPA + 动态加载 + 三大光学模块卡片导航）的基础上，基于 v4.0 材料完成以下升级：

## 新增实验模块（8 个）

- **物理光学（7 个）**：新增 迈克尔逊干涉仪、双缝干涉与光栅衍射
- **几何光学（5 个）**：新增 光学像差分析、望远镜系统设计器、显微镜光学系统
- **现代光学（5 个）**：新增 傅里叶光学 4f 系统、激光谐振腔设计器、光子晶体带隙仿真

## 现有模块升级（10 个）

- 全部仿真组件更新为 v4.0 版本：更完善的物理引擎、3D 可视化、实验模式与移动端适配
- 引入共享实验面板组件（ControlPanel / TearOffPanel / Knob / ExperimentChecklist）
- 引入实验状态缓存（localStorage 持久化，切换模块后自动恢复参数）
- 引入可视化快照捕获与撕下面板（跨模块对比）
- 更新衍射物理引擎（`src/lib/optics/diffraction.ts`）与工具函数（含高 DPI 画布修复）

## 交互与体验改进

- 导航、返回与 Escape 快捷键覆盖全部 17 个模块
- 更新样式表（响应式、移动端触控优化、自定义滚动条）
- 页面版本号更新为 v4.0

## 修复（相对 v4.0 材料的两个运行时问题）

- 修复 `use-experiment-state.ts` 中 `hasRestored` 重复声明（会导致模块加载报错）
- 删除 `MichelsonInterferometer.tsx` 中引用了未定义变量 `i` 的死代码

## 构建验证

- `npm install` + `npm run build` 通过（Next.js 16，Turbopack）
- 产物 JS 全部通过语法检查，17 个模块代码分割 chunk 均生成
- 本地 `next start` 冒烟测试通过（首页 200）
